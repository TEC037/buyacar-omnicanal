# Reglas Go

- Usa la versión estable vigente consultada en `go.dev`.
- Propaga `context.Context` en toda E/S y usa `log/slog`.
- Mantén dependencias mínimas y justifica cada una en un ADR.
- Ejecuta `gofmt`, `go test`, `go test -race`, `go vet` y `staticcheck`.
- No ocultes errores ni uses `panic` para flujo normal.
- Todo adaptador externo debe tener interfaz, stub y prueba determinista.
