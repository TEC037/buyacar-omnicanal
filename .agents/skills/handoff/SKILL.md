# Skill: handoff

Crea `production_artifacts/handoffs/cycle-N.md` con:

- objetivo y alcance;
- archivos creados/modificados;
- comandos y resultados;
- tests pendientes o fallidos;
- decisiones/ADR;
- riesgos y bloqueos;
- siguiente acción exacta.

Actualiza `production_artifacts/STATUS.md` con el ciclo, modo, puerta y responsable.
