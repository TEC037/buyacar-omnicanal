# Skill: spec-first

- Convierte requisitos en escenarios verificables.
- Separa MUST, SHOULD y MAY.
- Define estados de error, incertidumbre y escalamiento.
- Mantén `docs/SPEC.md`, `docs/adr/` y `production_artifacts/golden-cases/`.
- No inventes APIs: marca interfaces pendientes y crea stubs.
- Requiere aprobación humana sólo para decisiones irreversibles o de alcance.
